# Signum Platform TypeScript SDK

SDK TypeScript interne reserve aux portails Signum et aux surfaces back-office
GUOT.

Ce package n'est pas destine aux integrateurs finaux. Il couvre les APIs de
plateforme:

- depot et complements KYC publics;
- administration GUOT;
- espace client tenant;
- espace developpeur;
- abonnements, tenants, domaines et branding.

Le SDK public integrateur reste `@signum/pki-sdk-typescript`.

## Build

```bash
npm install
npm run build
npm test
```
